reins.

握住你 AI 编码智能体的缰绳 —— 一个本地、确定性的可验证执行证据层：工具执行前的策略门，执行后的防篡改账本，以及回放与取证。

它做什么

与沙箱叠加而非竞争：沙箱约束智能体*能碰到什么*，reins 证明*它请求过什么、依据哪套策略、记录本身是否可信*。

🚦

策略门 exec 前

YAML 声明 allow / ask / deny。结构化匹配程序+旗标（含组合短旗标与包装感知：rm -fr、sudo rm -rf、find -exec rm 都归一到 rm）、原始正则抓 curl … | sh、路径 glob 保护 .env / .ssh/ / *.tfstate*。

⛓️

防篡改账本 exec 后

每次判决追加进 JSONL 会话文件，SHA-256 哈希链——每条记录承诺前一条。reins trace verify 校验；链条损坏时 hook 拒绝继续记录（fail-closed）。

🛡️

默认 fail-closed

载荷畸形、策略加载失败、账本被篡改 → 一律拦截。与"agent 删掉拦截它的 hook 后全部放行"（anthropics/claude-code#32990）的失效模式正好相反。

🔁

策略回放 绝不执行

reins replay <session> --policy stricter.yaml 用候选策略重放历史会话，报告"哪些会被拦"。只重演判决，不跑任何命令——在采纳更严策略前先验证。

🧬

6 个 agent 适配器

Claude Code、Gemini CLI、Codex、Grok Build、opencode、pi 一个 reins init 装上钩子，外加通用 reins exec -- 包住脚本/CI/其他 agent。所有适配器写入同一本账本，按 agent 分文件。

🖥️

双语 TUI v0.10

裸 reins 或 reins ui 打开交互式会话浏览器：彩色判决时间线、事件钻取、就地校验。首次运行选语言（English / 中文），非 TTY 与 NO_COLOR 自动降级。

🔍

只读 MCP server

reins mcp 向 agent 暴露 check_command、recent_decisions、policy_summary、stats、suggest_alternative：撞墙前自查、回顾被拦记录、要更安全的替代表。工具全只读，hook 执行时重新判决。

📸

取证快照

reins snapshot 输出取证 Markdown 卷宗：完整性裁定、策略指纹、完整时间线、每个被改文件的 git 状态与恢复指引（git restore / git reflog）。篡改的账本也能出报告——证据保留、篡改被标注。

安装 & 使用

三步开始，重启 agent 会话（或跑 /hooks）加载新 hook。

  1. 全局安装
    npm i -g reins
  2. 为你的 agent 装上策略 + hook（自动备份原配置）
    reins init claude  |  gemini  |  codex  |  grok  |  opencode  |  pi
  3. 日常使用（都是实时判定的只读/审计命令）
    reins doctor · reins trace list · reins trace verify · reins trace show · reins trace export · reins replay <session> --policy y.yaml · reins snapshot · reins ui

reins 是策略与审计层，不是 OS 沙箱——够创造力的 agent 仍可能找到未分类形态。要硬隔离请与 bubblewrap/Seatbelt/microVM 叠加。
